# Windows 版本变更记录

参考 [Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/) 分类整理。与 Mac 版本独立；相同版本号不代表相同功能。历史描述以每版验证记录为准，不将源码/编译通过视为真实 WLAN 认证成功。

原记录没有明确发布日期的版本标为“日期待核实”，不以文件修改时间推断发布日期。Windows 未单独留存构建序号，使用对应产品版本；不套用 Mac 构建号。以后发布要求见 [统一发布规则](../macos/docs/release-policy.md)。

### 验证与限制

- 74/74 逻辑测试通过，已构建 x64 自包含程序与安装器；独立解包确认仅含程序、说明和安装器组件，程序与构建输出一致。
- 无需迁移账号数据；不改变凭据管理器、WLAN 配置或认证逻辑。本次在 Mac 构建，Windows 真机安装与 Wi-Fi 认证仍需目标设备验证。

## [0.1.9] - 日期待核实

产品版本：0.1.9；独立构建号：未留存。

### Fixed / 修复

- 认领当前连接后最多等待五秒、连续三次匹配再确认，避免短暂状态延迟立即报错。
- 认领拥有独立忙碌状态，阻止并发认领/连接和过期刷新。
- 超时提示绑定具体连接，晚到的健康状态可清除自身旧错误，即使没有持久化失败记录；其他错误保留。
- 成功认领/连接清除错误样式，取消或挂起不保存虚假成功。

### 验证与限制

- 74/74 测试、Windows x64 发布及安装器负载校验记录。
- Windows UI、驱动时序及真实权限/持久化失败未在开发 Mac 复测。
- 依据：[版本验证记录](docs/verification-0.1.9.md)。

## [0.1.6] - 日期待核实

产品版本：0.1.6；独立构建号：未留存。

### Added / 新增

- 运行于提升权限会话时提示；增加认领当前连接入口及读回检查。

### Fixed / 修复

- 新建配置默认所有用户范围，减少普通/管理员登录会话间不可见问题；已有范围保留。

- 健康匹配连接清除已停止失败状态；稳定验证不依赖尚未写入的标记。

### Changed / 变更

- 连接前配置自动加入和优先级；项目合并桌面可运行版源码及测试，安装器版本对齐 0.1.6。

### 验证与限制

- 版本文档记录 Windows x64 编译与测试；桌面合并完整性报告中源码/测试无差异。
- 该版成功后仍写活动配置标记，后续诊断发现可能再次取消连接；0.1.7 调整写入时机。目标设备多种会话及超时场景仍需验收。
- 依据：[版本验证记录](docs/verification-0.1.6.md)。
- 合并依据：[桌面版完整性报告](artifacts/merge-desktop-0.1.6/integrity-verification.json)。

## [0.1.4] - 2026-10-20

产品版本：0.1.4；独立构建号：未留存。

### Added / 新增

- 完整连接诊断会话：阶段起止、时间、耗时、版本、系统环境、返回码、认证进展及最终结果。

## [0.1.0] - 2026-10-20
