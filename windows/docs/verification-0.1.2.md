# Windows 0.1.2 — 使用真实 Wi-Fi 名称

日期：2026-10-20。

## 行为变化

- 同一 SSID 的账号共用真实名称的 WLAN 配置，不再创建按账号命名的 `WiFiSwitch-…` 条目。
- 复用既有同名配置时，检查 SSID、公司策略及修改权限，保持原有用户范围；企业证书信任要求继续沿用。
- 连接前更新所选凭据。当前配置相同时等待断开完成后重新认证，不将旧会话当作新账号成功。
- 账号 UUID 记录于 Windows 配置的当前用户自定义数据中，不显示在 Wi-Fi 名称中，不含密码。
  此标记仍代表应用的连接记录，不是服务器实时身份查询。
- 启动及连接成功后清理旧版不在使用的条目，仅删除符合旧命名及 SSID 哈希的当前用户配置。
  活动配置、连接过程中的配置、状态不可读以及公司策略配置均保留。
- 兼容旧版连接与失败记录，不在启动时强行重命名当前连接。
- 新配置与旧配置相同、凭据已替换时，不能依赖旧配置自动恢复旧凭据；
  原配置不同且满足恢复条件时保留 0.1.1 的单次恢复行为。
