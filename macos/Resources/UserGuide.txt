WiFi Switch 使用说明

一、可以做什么

保存和切换 Wi-Fi 账号，支持企业 Wi-Fi、普通密码 Wi-Fi、手机热点和开放网络。一个账号可以关联多个 Wi-Fi，同一 Wi-Fi 也可以使用不同账号。

二、添加账号并连接

1. 打开 WiFi Switch，点击“添加账号”，填写备注、用户名和密码。企业 Wi-Fi 需要用户名和密码；普通 Wi-Fi 或热点只需密码；开放网络无需密码。
2. 在“关联 Wi-Fi”中勾选网络，也可手动输入准确的 Wi-Fi 名称。允许定位权限后可扫描附近网络。点击“保存”。
3. 展开账号，点击目标 Wi-Fi 旁的“连接”，选择：
   • 同步账号：连接成功后，将该账号和密码保存为此 Wi-Fi 的系统连接凭据，供系统以后重连使用。
   • 仅本次连接：本次使用所选账号，保留系统原来保存的账号和密码。
   • 取消：保持当前连接。

切换账号会短暂断网。连接过程中如出现系统授权或证书提示，请按提示处理后返回。

三、从菜单栏使用

点击屏幕顶部的 WiFi Switch 双向箭头图标，可查看当前网络、账号和连接状态；展开“其他网络”即可选择已保存的账号与 Wi-Fi 连接。

• 绿色对钩：账号连接检查与互联网检测通过。
• 黄色叹号：账号未登记或保存的密码需要更新，点击按提示处理。
• 灰色信息标记：账号信息尚未核对，点击后选择“核对”。
• 红色叉号：未连接或网络异常，点击查看详情。

系统已经连接 Wi-Fi 时，可点击主窗口的“添加此配置”，或菜单栏的黄色叹号，读取系统保存的账号信息并添加到应用。发现密码不一致时，确认后更新；同一账号关联的所有 Wi-Fi 共用这份密码。

关闭主窗口后仍可从菜单栏使用。再次打开应用会唤起已有窗口，不会运行第二个实例。齿轮菜单中的“配置管理”可重新打开主窗口，“退出系统”可完全退出应用，退出不会主动断开系统 Wi-Fi。

四、日常管理

• 添加或修改：账号旁的“⋯”可添加 Wi-Fi、修改账号或删除账号。
• 移除关联：Wi-Fi 行旁的“⋯ → 移除 Wi-Fi”只移除该账号与网络的关联。
• 查看网络：当前已连接的 Wi-Fi 行旁选择“⋯ → 查看 Wi-Fi 信息”，查看 IP、网关、DNS、信号等信息，可复制或刷新。
• 重新连接：选择 Wi-Fi 行旁的“⋯ → 重新连接”，使用该账号再次连接。
• 断线提示：点击“重新连接”使用上次账号尝试恢复；点击“取消”保持断开，同一次断线不会反复询问。关闭再打开系统 Wi-Fi 时，由 macOS 按自身设置连接。

删除账号会移除它在应用中保存的密码和全部 Wi-Fi 关联，不会让 macOS 忘记网络。

五、系统要求输入哪种密码

• “登录”钥匙串密码：通常是 Mac 登录密码。结合应用的授权说明核对当前账号、Wi-Fi 和条目名称，确认无误后可选择“始终允许”。
• 系统钥匙串管理员授权：输入这台 Mac 的管理员用户名和密码。
• Wi-Fi 认证：输入网络账号和密码；企业网络的证书信息请向网络管理员核实。

不同条目或应用更新后，macOS 可能再次要求授权。账号密码保存在本机钥匙串中，应用不会保存 Mac 授权密码。

六、再次查看说明

打开顶部“帮助 → WiFi Switch 使用说明”，或菜单栏“齿轮 → 使用说明”。说明保存在应用内，无需联网。
