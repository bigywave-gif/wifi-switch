## [0.1.64] - 2026-10-27

构建号：65

### Fixed / 修复

- 重装启动时，后台修改旧密码条目名称可能先触发一次授权，超时后正式核对又申请访问同一条目。取消启动、刷新和读取成功后的自动改名；新建或明确更新密码时仍写入可区分账号的条目名称。
- 自动核对说明先完成原生窗口绘制，再开始对应读取；读取来源切换时复用同一窗口。按登录钥匙串、系统钥匙串、普通 Wi-Fi 条目和应用账号密码显示当前账号、可能的系统条目名称及应输入的密码种类，避免系统管理员授权仍显示登录钥匙串说明。
- 应用账号密码授权等待改为后台读取，主界面继续刷新；账号或连接变化后丢弃旧结果，取消与拒绝不触发轮询重试。
- 手动核对已确认密码一致且没有写入时，复用本轮读取结论，取消同一操作末尾多余的第二次应用密码读取。实际写入后的回读和确认密码不同的稳定性检查仍保留。

### 验证与限制

- 277 项 Swift 测试／21 个 suite 通过，覆盖分来源说明先于读取、等待期间账号对应关系、失败不重试、过期结果丢弃、无写入只读一次和真实隔离钥匙串异步读取。原生预览确认系统／应用两阶段内容可见并复用同一窗口；详见 [验证及重复访问审查](docs/verification-0.1.64.md)。
- 保留启动自动核对，不保存或代填 Mac 授权密码。旧条目可能继续显示通用名称；不同条目和应用更新后的许可仍由 macOS 决定，不能保证只输一次、跨版本免授权或系统框与说明同时出现。
- 本次未改变密码存储格式、钥匙串 ACL、系统 Wi-Fi 设置或 Windows。新包不自动安装；真实旧条目重装后的完整弹窗次数尚待现场验收。

## [0.1.63] - 2026-10-27

构建号：64

### Changed / 变更

- 已连接 Wi-Fi 断开后，用户确认重连的默认等待由约 10 秒调整为约 3 秒，仍须用户点击“重新连接”才提交凭据；用户取消继续保持现状。
- 检测到系统 Wi-Fi 重新加入并获得可用 IP 时，取消尚未执行的重连提示，为系统连接保留约 3 秒缓冲，再进行可能弹授权的应用凭据核对；静默检查仍可执行，不修改系统自动加入设置。

### Fixed / 修复

- 系统已加入网络时，等待中的 WiFi Switch 重连提示可能仍保持排队；现在取消过期任务，并对第一次识别的系统连接立即准备好后续断线提示。
- 系统加入期间，暂不启动交互式账号核对，减少应用钥匙串授权与系统连接操作同时进行的机会；缓冲结束后继续既有自动核对，不跳过密码差异检查。

### 验证与限制

- 270 项 Swift 测试／21 个 suite 通过，包括默认等待计时、系统抢先恢复、缓冲期不读交互式密码、缓冲结束恢复核对及取消不重连；制品结果见 [验证记录](docs/verification-0.1.63.md)。
- 当次系统日志显示手动断开后系统临时停用自动加入，关闭 Wi-Fi 前未见 WiFi Switch 发起关联；没有足够证据将卡住归因于权限或确认本改动已解决系统卡住，需真实 Mac 复测。
- 不修改系统 Wi-Fi 自动加入、首选网络或凭据，不自动安装；Windows 不变。

## [0.1.62] - 2026-10-27

构建号：63

### Fixed / 修复

- 自动核对过程中，授权说明以前一直显示读取系统 Wi-Fi 凭据，即使正在读取 WiFi Switch 账号密码也未切换。现在说明随实际步骤更新，便于识别系统弹窗的目标；密码不显示在说明中。
- 同一连接的多个刷新同时发起静默比较时，先前可能启动多个重复核对；现复用进行中的同一轮结果。账号、网络、来源或连接事件变化后不复用旧结果，密码不同仍须第二次稳定读取。

### 验证与限制

- 268 项 Swift 测试／21 个 suite 通过，覆盖系统与应用条目读取步骤、并发核对合并、过期结果和真实差异二次稳定检查；制品结果见 [验证记录](docs/verification-0.1.62.md)。
- 登录钥匙串解锁、系统 Wi-Fi 条目和应用账号条目为不同权限，macOS 仍可能分别要求授权；本版不保证合并为一次输入或跨版本免授权。真实设备三次弹窗是否减少仍需现场验收。
- 不改系统 Wi-Fi 设置、密码或钥匙串访问控制，不迁移用户数据；Windows 不变，安装包不自动安装。

## [0.1.61] - 2026-10-27

构建号：62

### Changed / 变更

- 新建或更新账号密码时，钥匙串条目名称显示账号描述与短标识，便于区分办公、项目等账号；相同描述的条目也带不同标识，不展示密码。
- 升级和修改账号描述后，尝试在独立非交互进程中仅更新旧条目的名称，保留原有密码及访问控制；获授权读取账号密码后再尝试一次。读取或修改权限不足时保留原条目，不为改名另行申请授权。

### Fixed / 修复

- 所有账号原先都显示“WiFi Switch 账号密码”，无法从钥匙串提示判断被访问的账号。新条目和成功迁移的旧条目显示对应账号名称。
- 账号密码及名称同时修改后若配置保存失败，回滚原密码与原账号名称，避免条目显示与保存配置不一致。

### 验证与限制

- 266 项 Swift 测试／21 个 suite 通过；隔离临时钥匙串验证原密码在改名后保留，新建、重名区分和失败回滚通过。发布结果见 [验证记录](docs/verification-0.1.61.md)。
- macOS 决定旧条目是否允许静默改名，权限不足时可能仍先显示旧名称；本版不保证跨版本或多条目只授权一次，真实账号条目及弹窗仍需现场验证。
- 无需迁移账号配置或密码；不修改系统 Wi-Fi 凭据和 Windows 代码，安装包不自动安装。

## [0.1.60] - 2026-10-27

构建号：61

### Changed / 变更

- 已连接的 Wi-Fi 断开或持续没有可用 IP 时，等待系统自行恢复后询问是否使用上次账号重新连接；取消保持现状，同一次断线不重复询问。确认后只执行一次连接，失败后等待用户处理。
- 系统通知不提供断开来源，因此用户主动断开与原因不明的掉线均可能触发确认；应用不声称能够区分二者。Wi-Fi 被关闭、系统已连接其他网络或系统已经恢复时不主动连接。

### Fixed / 修复

- 用户在系统 Wi-Fi 中主动断开后，应用此前可能在延时结束后重新连接；现在只有用户确认后才发起重连。确认期间连接、账号或 Wi-Fi 状态变化会使旧请求失效，不抢占系统连接。
- 取消确认不会读取密码；重连使用中断前的账号并沿用保留系统首选凭据的连接路径。

### 验证与限制

- Swift 测试覆盖确认、取消、重复事件、系统抢先恢复、账号／网络变化和失败后不重复重试；实际结果及安装包见 [验证记录](docs/verification-0.1.60.md)。
- 保留原有系统 Wi-Fi 自动加入机制和首选设置，无需迁移数据，Windows 未改动；实际设备的主动断开和异常掉线仍需现场验收。

## [0.1.59] - 2026-10-27

构建号：60

### Fixed / 修复

- 0.1.58 将所有由应用连接的企业 Wi-Fi 都强制显示灰色“未核验”，即使连接调用成功、目标网络和 IP 已确认且互联网正常。现在由应用完成所选账号连接后，主面板和菜单栏使用一致的绿色连接状态。
- 成功连接后的最终状态再次要求可用 IP；连接调用失败或最终没有可用 IP 时不标记成功，互联网检测失败仍显示红色。
- 应用自动重连与系统自行恢复继续分开处理：系统抢先恢复时重新识别系统账号，不将上次选择的账号当作应用已重新认证；不同的系统保存默认账号不触发本次应用会话密码更新。

### 验证与限制

- Swift 自动化测试覆盖所选企业账号、系统默认账号不同及不可读取、IP 不可用、互联网可达／不可达、系统抢先恢复与旧状态失效；结果及制品验证见 [验证记录](docs/verification-0.1.59.md)。
- 绿色表示应用提交所选凭据后的连接调用、网络及互联网检查通过；这不是从认证服务器直接读取到的会话用户名。真实 Example-Enterprise 双账号与业务权限仍需现场验证。
- 不改变系统首选或自动加入设置，不读取额外密码，无需数据迁移，Windows 未改动，安装包不自动安装。

- 无需数据迁移，不改变系统自动加入或首选账号，不修改 Windows；安装包不自动安装。

## [0.1.57] - 2026-10-26

- 后台比较在禁止钥匙串交互的独立辅助进程中完成，4 秒超时按不可用；30 秒结果缓存及网络事件失效。进程间只传账号标识和比较结果，不传密码或摘要；只有用户确认保存时才写应用钥匙串。存在身份冲突、连接变化或账号已被编辑时停止，不覆盖错误对象。

### 验证与限制

- 195 项 Swift 测试通过，包含企业与个人网络更新、同账号多 Wi-Fi、同密码不合并热点、补关联与更新回滚、取消／读取拒绝／网络或身份改变、缓存失效和过期异步结果丢弃。原生模拟界面与发布检查详见 [0.1.47 验证](docs/verification-0.1.47.md)。
- 此版本无需数据迁移。Windows、主配置面板布局和系统首选顺序／自动加入设置未修改；新包未替换本机安装。
- 比较对象是系统保存凭据，不能据此证明本次服务器认证身份；无权限时无法自动确认差异。真实设备改密、钥匙串授权及企业网络切换尚待目标环境验收，模拟测试不能替代这些验证。
