# Mac 版本变更记录

按 [Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/) 整理，最新版本在前；分类使用 Added（新增）、Changed（变更）、Fixed（修复）、Removed（移除），有弃用或安全修复时再增加 Deprecated / Security。版本编号政策见 [发布规则](docs/release-policy.md)。历史内容描述当时版本，不应当作最新版功能说明。

日期采用 Asia/Shanghai；构建号无直接证据时明确标注未核实，不按版本号推算。0.1.0 的初始版本归档日期取初始验证记录；0.1.9 是失败的本地试验，不作为正常内部发行。部分历史安装包已清理，保留记录不代表仍可下载。

## [Unreleased]

### Added

### 验证与限制

- 本次仅补录文档并完善后续发布流程；不会改写已发布安装包，不代表历史 BUG 均已实机复测。

## [0.1.34] - 2026-10-21

构建号：35

避免误弹添加配置。

### Fixed / 修复

- 子进程无法读取 SSID 时使用主进程已确认名称并再次核对连接；补充旧系统 EAP 条目的用户名属性查询。
- 只有成功取得身份且确认配置缺失才自动提示添加；读取失败、冲突和歧义不误报新账号。
- 识别出已有账号后撤销先前自动添加提议，手动窗口保持用户控制。

### 验证与限制

- 154 项测试；真实只读身份路径匹配到一个已存账号；签名及包校验通过。
- 不读取密码；未验证真实密码导入与完整企业网络重连。
- 依据：[验证/交付记录](docs/verification-0.1.34.md)。

## [0.1.33] - 2026-10-21

构建号：34

系统账号识别、导入与同步选择。

### Added / 新增

- 按系统保存的 SSID、安全类型及用户名匹配已存账号，未知或歧义保持未知。
- 新增独立导入窗口：命名并确认后读取系统凭据；取消后按 SSID 记住不再提示。
- 连接前提供同步账号/仅本次连接/取消；不同步时保存并恢复原系统凭据。

### Fixed / 修复

- 网络变化或取消丢弃迟到导入结果，存储失败回滚；相同配置可复用。

### 验证与限制

- 146 项测试、隔离导入 UI、安装包校验通过。
- 系统保存用户名不是本次 EAP 认证身份；真实企业重连、导入及权限仍需目标设备验收。
- 依据：[验证/交付记录](docs/verification-0.1.33.md)。
