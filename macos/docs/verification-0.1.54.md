## 界面验证与边界

以生产 AppModel、MenuPanel、SystemImportView 和 SystemImportWindow 构建隔离原生预览，数据及凭据均为虚构、仅保存在内存中；未触碰真实 Wi-Fi 或钥匙串。

确认灰色可点击按钮的辅助功能标签为“暂时无法核对账号信息，点击核对”；点击打开“核对账户信息”，显示示例 SSID、账号与用户名；取消后可回到菜单。后续预览进程退出，未取得完整拒绝／更新分支的界面验收；对应分支已有自动化测试证据。

读取失败日志使用固定事件 verificationReadFailed／importReadFailed，可选系统错误码；不记录原始错误描述、网络名、账号或密码。诊断写入失败不得阻断核对。

真实热点切换、钥匙串权限和系统授权窗口尚待现场验收。主配置管理面板布局与 Windows 不变。未自动安装。
