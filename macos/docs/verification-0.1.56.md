# macOS 0.1.56 验证记录

日期：2026-10-26（Asia/Shanghai），构建 57。

## 代码与自动化

245 项 Swift 测试／20 个 suite、9 项发布规则测试及 15 项签名门禁测试通过；git diff --check 通过，Windows 没有工作区变更。

- 企业／个人 Wi-Fi 初次核对、系统回切后静默读取受限时自动核对，不要求先点击灰色标记。
- 热点导入、切走、回切后实际重新读取与本应用密码一致，恢复绿色；再次修改系统密码后返回黄色，不自动覆盖。
- 取消／失败抑制同一连接的定时及重复通知请求；离开网络后重置机会，重启可重新核对。旧的每构建 UserDefaults 标记不再限制运行。
- 授权期间同一网络通知使旧结果失效，成功读取后重试最新连接；失败／取消与重复通知同时发生时不连续请求授权。
- 比较差异要求两侧密码、来源与身份二次读取稳定；连接或账号变化不发布旧结果。
- 提示包含账号描述、SSID、适用的用户名，不含密码。个人网络密码查询传入操作说明，不设置 ACL 或写入系统条目。
- 自身切换期间不竞争读取；直接连接已有账号使用本应用密码，后续独立系统连接事件重新核对。

测试日志：`.build/manual-verify/56-tests.log`。固定事件 automaticVerificationStarted／Completed／Failed 替代仅启动阶段命名；运行日志仍不含账号、SSID、密码或摘要。

## 边界与升级

实际 Example-Hotspot 热点的系统钥匙串授权复用尚未现场验收。使用与导入相同的系统读取路径，保留固定应用签名和原有条目权限；macOS 是否复用既有授权仍取决于钥匙串 ACL 和设备策略。不能把一次管理员授权等同于永久授权。此修复不更改 ACL，不保存管理员密码，不以条目修改日期或旧密码摘要代替实际比较。

CoreWLAN 系统授权窗口没有自定义文案接口，应用说明窗口补充正在核对的账号；个人网络查询传入操作说明，但不承诺每种系统对话框都显示该文案。

账号数据无需迁移，不自动安装。
