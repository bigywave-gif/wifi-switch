# macOS 0.1.55 验证记录

日期：2026-10-26（Asia/Shanghai），构建 56。

## 自动化

240 项 Swift 测试／20 个 suite、9 项发布规则和 15 项签名门禁测试通过。

- 企业和个人网络首次静默不可读自动读取，等值无需导入窗口且不重写密码。
- 差异经过系统及应用保存值二次稳定核对才变黄，不自动改密码。
- 取消／失败后刷新、重连、同版本新建模型不再自动读取，主动重试仍可用。
- 初次静默成功后，后续换网的不可读不触发授权。
- 授权未完成时禁止编辑及竞争读取；换网后丢弃旧结果。
- 直接切换保存账号不读取系统配置进行启动核对。
- 版本标记在核对前保存，新构建才获得新的机会，不存凭据。

## 原生界面

隔离预览使用生产 ContentView、MenuPanel、AppModel 与虚构内存服务，未读取真实钥匙串或连接网络。首次显示无需点击核对即为绿色；点击模拟不可读、差异、断网后，主面板顶部点、当前账号标记、当前 Wi-Fi 标记与菜单分别同为灰色、黄色、红色。布局未重排。

实际管理员授权弹窗与跨账号系统钥匙串权限未做现场验收。“始终允许”是 macOS 条目权限，不能宣称一次允许后所有条目免授权。应用凭据继续使用 SecItemUpdate 保留条目，不重建条目或修改 ACL；系统首选保护与回滚读写保持原有检查，不以旧凭据缓存代替读取。

新包不自动安装；Windows 无修改。

签名测试最初发现旧夹具缺少 README／CHANGELOG 且 Info.plist 非法；补齐隔离夹具后 15 项通过，未修改真实签名流程。打包仍使用持久签名身份并检查旧指定要求，避免以新身份替换已有应用。
