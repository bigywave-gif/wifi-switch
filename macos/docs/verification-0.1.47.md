# 0.1.47 / build 48 验证

日期：2026-10-22。

## 实现范围

- 已有账号 + 已有 Wi-Fi 关联：系统保存密码与应用密码不同，菜单栏黄色叹号打开更新窗口，确认后更新应用密码。
- 已有企业账号 + 未关联 Wi-Fi：按唯一用户名匹配展示已有账号，确认后补关联；同时改密需再次明确“添加并更新”。账号 ID、名称、原关联保留，不重复创建。
- 新账号与新关联：填写描述并添加。普通热点没有用户名，不能跨 SSID 按相同密码推断同一账号。多候选或认证类型冲突停止。
- 只读比较返回 same / different / unavailable，不传输密码或摘要；授权不可用显示待核对。使用独立辅助进程关闭交互，超时 4 秒、结果缓存 30 秒、连接事件重新核对。后台不通过弹授权窗口持续重试。
- 使用系统保存配置进行比较，不能证明认证服务器实际接受的实时身份；应用本次“仅本次连接”成功会话不与旧默认账号比较。
- 明确过期账号在本次运行中停止用旧密码自动重试；更新或手动连接成功后恢复。此额外状态不跨进程持久化，重开应用依赖重新核对。

相关 API 合同参见 [Apple SecKeychainSetUserInteractionAllowed](https://developer.apple.com/documentation/security/seckeychainsetuserinteractionallowed(_:))及本机 Security SDK；该旧 Keychain API 已弃用，作为现有传统钥匙串读取的兼容路径保留。主进程交互模式不修改。

## 原生模拟界面

独立的 `.build/menu-import-preview/Menu Import Preview.app` 使用生产 MenuPanel、SystemImportView、SystemImportWindow、AppModel，注入内存仓库及模拟 Wi-Fi／系统身份／密码比较器。预览驱动显式展示配置窗口，不接触真实账号数据、钥匙串或网络。

已实际点击并观察：

1. 黄色叹号打开“更新已保存的密码”，显示对应 Wi-Fi 与账号，按钮为取消／更新，没有新增名称输入框。
2. 取消关闭窗口，菜单保持黄色；再次进入并确认更新后窗口关闭，当前账号不变且显示已连接对钩。
3. 模拟连接另一个企业 Wi-Fi，自动打开“添加 Wi-Fi 到已有账号”，显示原账号，按钮为添加。
4. 确认后新网络以原账号显示已连接，展开其他网络仍能看到原网络及同一账号。
5. 模拟断开后菜单显示断开状态；验证后退出预览。

更新窗口截图已视觉检查，文字、账号和按钮可见，无裁切。未操作实际系统 Wi-Fi。
