# 0.1.50 / build 51 验证

日期：2026-10-22。

## 现场事实与结论边界

用户确认使用 0.1.47，首次更新后恢复绿色，稍后黄色提示明确写“系统 Wi-Fi 密码与 WiFi Switch 中保存的不一致”，再次更新后正常。因此 0.1.49 修复的 unavailable 黄色提示并非当次直接原因；没有原比较值或来源诊断，不能确定是写入未生效、系统记录随后变化、来源不同或其他原因。

代码此前保存后无回读便发布 same；后台读取两个不同存储的值只各读一次，未携带本次导入来源。新版本分别添加保护，不通过永久缓存 same 或无条件忽略 different 隐藏实际差异：

- 成功保存后用 AccountRepository.password 回读，一致才记录成功、缓存 same；失败明确报告未核验。配置已经提交则同步到模型，避免失败重试误建重复账号。
- 导入结果携带 standardPersonal / user / system 来源。本次同一账号、身份、连接的后续辅助请求携带期望来源；改变来源返回 unavailable / sourceChanged。该记录仅内存保存，不改变存储格式；断开、换网、身份不匹配及应用连接后清除。
- 不同值再次读取系统和应用两边；身份、来源、值有变化或读取失败，不报告确认不同。稳定不同仍报告 different；相同路径不增加重复读取。
- 辅助管道只传身份、应用账号 ID、来源请求，以及枚举结果／原因／来源／错误码；不传密码或摘要。辅助进程保持禁止交互，不在后台触发授权。
- 诊断文件记录固定阶段、时间、版本、进程号、来源类别、结果和错误码；不包含 SSID、用户名、账号 ID、密码、摘要或任意错误描述。当前用户目录 0700、文件 0600；超过 64 KiB 后保留后半段再追加。不上传，不写系统钥匙串 ACL。

API 核对参考 [Apple SecItemUpdate](https://developer.apple.com/documentation/security/secitemupdate(_:_:)) 及本机 CoreWLANUtil.h；API 返回成功本身不是用户现场“随后仍一致”的证据。本版本没有修改系统默认同步／恢复的实现。
