## 兼容性与限制

已有账号启动时在独立进程禁止钥匙串交互，按 ID 尝试更新显示名称；账号描述变化后再次尝试，成功读取密码后也再次尝试。更新操作只设置标签，不删除重建、不读取或覆盖密码、不调整 ACL。无权限时原条目保留，并记录固定事件及错误码；首次授权弹窗可能仍显示旧名称。新账号保存密码时直接写入新标签。

历史测试证实本地自签名不能保证跨版本复用授权；两次点击“始终允许”的实际原因仍需区分是否为不同账号条目或同一条目的重复授权。本版只改善识别，不宣称减少弹窗次数或跨版本永久授权。真实旧条目静默迁移和原生弹窗显示仍需在目标 Mac 验证。
