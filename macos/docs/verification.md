## 用户报告的密码重输弹窗

通过截图与 10:54:53 左右的系统 `eapolclient` 日志确认：

1. 系统收到所选用户名和密码，日志明确记录 `password is specified`（密码值由系统遮蔽）。
2. 开始 EAP-PEAP 认证后，服务器响应 `MSCHAPv2 Error = 691, Retry = 1`。
3. 随后状态变为 `UserInputRequired`，系统请求 `UserPassword`，与用户截图中的弹窗一致。

因此该次弹窗的直接原因是提交凭据后的认证拒绝，而非没有读取已保存密码。691 是认证失败码，不能单独证明密码错误、用户名格式错误或账号策略限制中的哪一种。未对真实账号进行自动重试，也未修改系统保存的 EAP 凭据。

参考：[RFC 2759 §6](https://www.rfc-editor.org/rfc/rfc2759.html#section-6)。
