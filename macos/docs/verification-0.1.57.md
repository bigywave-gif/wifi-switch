# macOS 0.1.57 验证记录

日期：2026-10-26（Asia/Shanghai），构建 58。

## 自动化验证

- 252 项 Swift 测试／20 个 suite 通过。
- 9 项发布规则测试、15 项签名规则测试通过。
- 应用最后连接 Studio、系统保存 Group 时：断线恢复提交 Studio 凭据，保留 Studio 会话及成功提示，后续普通轮询不以 Group 默认凭据覆盖。
- 系统在扫描前、扫描后或读取凭据期间恢复时：驱动返回独立的 systemRecovered 结果，不执行目标账号认证，不报告目标账号成功；模型重新识别系统账号，无法识别时保留未确认提示。
- 实际自动恢复顺序：准备网络、保存系统原凭据、再次检查系统是否恢复、断开残留关联、提交账号凭据、连续三次确认 SSID/IP、恢复原系统凭据。认证失败时恢复原凭据并报告失败。
- 关闭再打开 Wi-Fi：不发起应用旧账号恢复；系统连接后读取系统账号。其他网络、权限不足、休眠、失败次数限制的已有测试继续通过。
- 旧账号成功提示仅在对应连接失效后清除；无关操作错误不受影响。

测试日志：`.build/manual-verify/57-tests.log`。测试使用内存凭据和模拟网络驱动，不访问用户真实密码。
