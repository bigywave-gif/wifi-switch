# 0.1.38 / build 39 验证

日期：2026-10-22。仅修改 Mac 菜单栏及对应测试、文档和发布信息；未修改 Windows、真实账号或网络配置，未替换本机已安装应用。

## 改动

- 齿轮菜单移除“添加当前 Wi-Fi 配置”，保留配置管理、关于、使用说明、退出系统。
- 顶部独立展示系统当前 SSID 与已确认账号；未知账号、等待 IP、未连接、Wi-Fi 关闭分别显示对应状态。
- 其他网络每次打开默认收起。展开后按 Wi-Fi 与账号组合提供原有连接入口；仅排除已确认的当前组合，保留同 Wi-Fi 其他账号和当前账号其他 Wi-Fi。
- 配置管理主窗口保持原布局；连接提示、菜单宽度及原连接流程保持。

## 验证

Swift Testing：163 项、13 suites 全部通过。新增测试覆盖当前组合排除、同 SSID 其他账号保留、其他 Wi-Fi 保留、未知/断开不误隐藏、未关联账号不产生连接入口。

原生 UI：用独立 bundle 的窗口承载生产 MenuPanel，内存账号和模拟 WiFiServicing。截图及 AX 验证默认收起、独立当前网络、展开可连接、模拟切换后顶部账号及其他列表同步变更、齿轮无添加当前配置、连接成功提示保留。没有连接真实网络。窗口预览验证了生产组件；未对用户已安装应用做重启或替换。
