## 现场依据与边界

本机不含凭据的旧日志显示 0.1.50 在 15:23:16 完成 importRead / savedPasswordVerified，15:23:49 的禁止交互后台查询返回 -25293，并将结果应用为 unavailable。这支持“添加成功后后台读取不可用推翻已验证状态”的问题定位，不代表管理员密码错误，也不能仅凭错误码断言钥匙串拒绝的唯一内部原因。

保存回读一致是当前连接内的证据，不是永久缓存；后续静默比较确认不同仍会提示更新。断开、换网、连接事件、休眠及账号改变触发重查。系统管理员授权与密码条目的“始终允许”由 macOS 管理，不保存管理员密码，不绕过权限，不保证升级或钥匙串锁定后永不授权。

网络检测要求 Wi-Fi 路径，正常 TLS 证书校验，目标 www.apple.com / www.microsoft.com:443。一次探测最多 4 秒，两轮；30 秒周期。结果只代表探测端点可达性；代理、VPN、门户登录、企业屏蔽可能导致局部网络可用但检测失败，不代表所有网站或内部服务的完整验收。

界面验证中途电脑锁定，未继续人工验证更新窗口的完整点击链；真实钥匙串授权、真实热点首次添加及断网恢复仍需安装后现场验收。单元测试与隔离界面验证不能代替这些场景。新包未自动安装，也未改变当前连接。
