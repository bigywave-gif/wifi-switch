# 0.1.45 / build 46 验证

日期：2026-10-22。

## 修改范围

- 菜单栏当前连接：已确认账号绿色对钩；未知账号黄色叹号，可点击打开已有系统配置导入窗口；断开连接或关闭 Wi-Fi 为红色叉号。
- 只在连接信息可读、已分配可用 IP、没有冲突操作时提供导入。等待 IP、正在确认、无权限读取名称和没有网卡分别提示；不把未知状态误报为断线。账号本身需核对但仍存在时不重复新增。
- 导入窗口使用“Wi-Fi 描述”作为新增账号名称，按钮为“添加”。沿用原有确认读取、取消、重复配置校验和保存逻辑；密码只在点击添加后读取，存入应用钥匙串，普通 Wi-Fi 无用户名，开放网络无密码。
- `Views.swift` 的主配置面板内容未变，`AppModel` 仅新增菜单状态及入口，未修改连接/重连、系统凭据写入、自动加入或存储格式；Windows 源码、配置和制品未修改。

通过原生 UI 工具实际点击并观察：

1. 未登记的“示例家庭热点”显示蓝色 Wi-Fi 图标、未知账号与黄色叹号。
2. 点击叹号打开独立添加窗口，描述为空时添加按钮禁用。
3. 点击取消后窗口关闭，黄色叹号保留；可再次打开。
4. 填写“家中热点”并添加后窗口关闭，当前连接显示该描述与绿色对钩。
5. 模拟断开后显示“Wi-Fi 已断开连接”及红色叉号；恢复后再次识别已添加账号，显示绿色对钩。
6. 验证宿主已退出。主配置管理面板没有被替换或操作。

已观察上述菜单内容及弹窗的原生截图。宿主将生产菜单放入独立窗口，未把这一验证等同于正式包 MenuBarExtra 外壳、真实网络认证或系统钥匙串授权验收。
