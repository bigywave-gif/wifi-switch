# macOS 0.1.52 验证记录

日期：2026-10-26；构建号：53。

继承 [0.1.51 验证](verification-0.1.51.md) 的自动导入核对、网络检测、原生菜单和真实只读外网探测结果。0.1.51 包生成后的复核发现：快速重连同名 Wi-Fi 的连接事件没有清除旧来源限定与比较结果，虽然一致证据已经失效，仍可能影响新连接。0.1.52 将这些状态一并失效；补充无需断开快照即可清除来源的回归断言。

- 最终源码：224 项 Swift 测试、20 个 suite 通过，9 项发布规则测试通过。
- 本次只改重连状态失效逻辑，没有更改互联网探测器或 UI 布局。主配置面板、Windows 保持不变。
- 尚未在用户真实热点上验证钥匙串授权和重新连接；界面验证中途电脑锁定，因此没有冒充完整现场验收。必要的系统授权无法由应用承诺永久免除。
- 无数据迁移；旧 0.1.51 包保留，新包不自动安装。
