# 新版本说明模板

复制以下结构到对应平台 CHANGELOG.md 的 Unreleased 之后，替换所有占位内容；删除没有变化的分类。Mac 打包不接受未替换的占位符。

```markdown
## [X.Y.Z] - YYYY-MM-DD

构建号：N

### Added / 新增

- [待填写：新增入口或能力、使用方法。]

### Fixed / 修复

- [待填写：什么场景下出现什么问题，现在如何处理。]

### Changed / 变更

- [待填写：默认行为、布局或兼容性变化。]

### 验证与限制

- [待填写：实际测试结果与证据链接。]
- [待填写：真实设备未验收项、升级影响或无需迁移。]
```

移除、弃用和安全修复按需增加 Removed、Deprecated、Security 分类。测试尚未执行时如实说明，不把计划写成已通过。发布后不可用相同版本号覆盖旧包。
