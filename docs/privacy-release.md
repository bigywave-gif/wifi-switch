# 发布内容与隐私边界

公开源码、界面示例、测试和文档仅使用虚构的账号与网络名称。测试凭据由固定的合成值或随机值构造，不从用户的密码库、网络配置或运行日志复制。示例 IP 使用文档地址段，示例 MAC 地址使用本地管理地址。

## 发布内容

- macOS 0.1.68（build 69）保持 DMG 格式。签名前剥离调试及源路径符号，生成 HFS+ 镜像时不复制宿主来源扩展属性，挂载后重新校验应用签名、内容和隐私边界。
- Windows 0.1.10 保持 x64 EXE 安装器。载荷只包含应用、使用说明、卸载程序和安装器组件；独立解包同时检查单文件程序中的应用程序集。
- 账号配置、密码库、日志、数据库、签名私钥及本机目录不属于发布载荷。Git 忽略规则和独立载荷检查共同约束这一边界。
- 历史文档中的现场名称和设备信息已做脱敏，保留原有验证结论，不将示例数据写成真实连接结果。

## 升级兼容

Mac 使用通用应用标识 `org.wifiswitch.WiFiSwitch`，保留原账号配置目录。已有账号按 UUID 查询钥匙串条目属性并识别此前的产品服务名；这个识别过程不请求密码数据、不硬编码历史个人命名，也不导出或批量复制凭据。多个旧候选或权限错误均明确失败。

系统可能重新请求定位或钥匙串授权，部分界面偏好可能恢复默认。升级前应退出旧版本。本次兼容性测试使用独立临时钥匙串与合成凭据，不代表所有用户的系统授权或企业认证环境已完成实机验收。

## 验证

本次通过 284 项 Swift 测试、74 项 Windows 逻辑测试、10 项发布规则和 19 项签名规则测试。另检查源码、历史 Git 对象、安装包文件表、应用程序内容和下载后的校验和。

发布内容脱敏不删除使用者自己的本地账号。应用安装后创建的账号配置和系统凭据仍属于使用者本机数据，升级时保留。GitHub 或第三方已保存的旧对象缓存、克隆和下载副本不受新版本发布控制。
